# Mr. & Mrs. Claus

A 7x7 cluster-pays Christmas slot for Stake Engine (engine.io, team `smukiez`, game `santas-wonderland`).

* `front/` is the front-end bundle exactly as it goes up to engine.io's **front** scratch area
  (`index.html` at its root). The math bundle is already published on engine.io (math v1).
